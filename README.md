# LLM-Powered Python Projects

A collection of two small projects exploring practical uses of large language models (LLMs) with Python and the Groq API.

## 📁 Projects

### 1. Voice Command Intent Classifier — `project1-intent-classifier`

Classifies in-car voice commands into intents (navigation, media, climate control, phone) using the LLaMA model via the Groq API. Shows how a voice assistant can map free-form speech to specific actions. API keys are handled securely using environment variables.

### 2. AI-Powered Test Result Analyzer — `project2-test-analyzer`

Reads JSON test results, identifies failures, and uses an LLM to generate root-cause analysis and suggested fixes — simulating an automated quality-assurance workflow.

## 🛠️ Built With

- **Language:** Python

- **AI:** Groq API (LLaMA model)

- **Data format:** JSON

## ▶️ How to Run

1. Clone the repo: `git clone https://github.com/Gayathri-hub-cell/llm-projects.git`

2. Install the Groq client: `pip install groq`

3. Set your Groq API key as an environment variable named `GROQ_API_KEY`.

4. Open the folder for the project you want and run its Python file.
